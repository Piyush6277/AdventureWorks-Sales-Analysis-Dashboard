# AdventureWorks Sales Analysis Dashboard

This project focuses on analyzing AdventureWorks business data using Power BI to generate meaningful insights related to sales performance, customer behavior, product trends, revenue growth, and overall business performance.

The project demonstrates data cleaning, data modeling, DAX calculations, dashboard development, and business intelligence reporting using interactive visualizations and real-world sales datasets.

---

# Project Workflow / Process

## 1. Data Collection
- Imported AdventureWorks dataset into Power BI
- Verified sales, customer, and product data

## 2. Data Cleaning & Transformation
- Removed null and duplicate values
- Cleaned and transformed data using Power Query
- Standardized data formats and column types

## 3. Data Modeling
- Created relationships between multiple tables
- Built structured data model for analysis

## 4. DAX Calculations
- Created calculated columns and measures
- Developed KPIs for sales and revenue analysis

## 5. Dashboard Development
- Designed interactive Power BI dashboards
- Added charts, slicers, filters, and KPI cards
- Created sales and customer performance visualizations

## 6. Business Insights Generation
Generated insights including:
- Sales performance trends
- Revenue and profit analysis
- Customer purchasing behavior
- Product category performance
- Regional sales insights
